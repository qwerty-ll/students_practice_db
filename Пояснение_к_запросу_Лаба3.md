# 🎓 Полное руководство к запросу Лабораторной работы №3
## Тема: Агрегатные функции SQL (`COUNT`), группировка (`GROUP BY`), фильтрация групп (`HAVING`) и реляционный условный подсчет через `LEFT JOIN`

> ⚠️ **Важно: запрос ниже проверен на тестовой базе `lab3` и ошибается в двух случаях** (подробно — в [Лаба3_сценарии.md](Лаба3_сценарии.md)):
> 1. **Теряет организацию, где никто не прошёл практику.** Из-за `INNER JOIN` к заявкам и `Практика_студента` подходящая организация с результатом 0 / 0 пропадает из ответа (в `lab3` — ООО ЮвелирСофт).
> 2. **Считает практики, а не студентов.** `COUNT(DISTINCT "Практика_студента"."Id_практики_студента")` посчитает студента дважды, если он прошёл в организации две практики (в `lab3` у Тензора получается 4 вместо 3). Нужно считать `DISTINCT "Id_студента"`.
>
> Правильный вариант запроса (на `LEFT JOIN`) и разбор всех сценариев — в [Лаба3_сценарии.md](Лаба3_сценарии.md).

## 1. Эталонный простой SQL-запрос (Без `CASE`, без `COALESCE`, без сокращений)

```sql
SELECT 
    "Доступные_места"."Наименование_организации",
    COUNT(DISTINCT "Практика_студента"."Id_практики_студента") AS "Всего_студентов",
    COUNT(DISTINCT "Студенты_направления"."Id_студента") AS "Студентов_направления"
FROM "Доступные_места"
INNER JOIN "Заявка_на_практику" 
    ON "Доступные_места"."Id_доступного_места" = "Заявка_на_практику"."Id_доступного_места"
INNER JOIN "Практика_студента" 
    ON "Заявка_на_практику"."Id_заявки" = "Практика_студента"."Id_заявки"

-- 1. Элегантный подсчет без CASE: присоединяем только студентов направления '09.03.02'.
-- Для студентов других специальностей LEFT JOIN подставит NULL, и COUNT их просто пропустит!
LEFT JOIN (
    SELECT "Студент"."Id_студента"
    FROM "Студент"
    INNER JOIN "Группа" 
        ON "Студент"."Номер_группы" = "Группа"."Номер_группы"
    WHERE "Группа"."Код_направления" = '09.03.02'
) AS "Студенты_направления" 
    ON "Заявка_на_практику"."Id_студента" = "Студенты_направления"."Id_студента"

-- 2. Отбираем организации, которые давали места для направления '09.03.02' каждый год
WHERE "Доступные_места"."Наименование_организации" IN (
    SELECT "Доступные_места"."Наименование_организации"
    FROM "Доступные_места"
    INNER JOIN "Практика" 
        ON "Доступные_места"."Id_практики" = "Практика"."Id_практики"
    WHERE "Практика"."Код_направления" = '09.03.02'
    GROUP BY "Доступные_места"."Наименование_организации"
    HAVING COUNT(DISTINCT "Доступные_места"."Учебный_год") = (
        SELECT COUNT(DISTINCT "Доступные_места"."Учебный_год") 
        FROM "Доступные_места"
    )
)
GROUP BY "Доступные_места"."Наименование_организации";
```

## 3. В чем гениальность и простота этого решения:

1. **Никаких непройденных функций:** Никакого `CASE WHEN THEN`, никакого `COALESCE`.
2. **Как работает подсчет студентов направления без `CASE`?**
   * Мы делаем `LEFT JOIN` к маленькому списку студентов направления `'09.03.02'`.
   * Если студент учится на `'09.03.02'`, его `Id_студента` успешно соединяется.
   * Если студент учится на любом другом направлении, `LEFT JOIN` подставляет **`NULL`**.
   * А по фундаментальному правилу Лекции 19 (Слайд 4): **агрегатная функция `COUNT(колонка)` игнорирует значения `NULL`!**
   * В итоге `COUNT(DISTINCT "Студенты_направления"."Id_студента")` считает только студентов целевого направления, возвращая точное число!
3. **Единый `GROUP BY`:** Запрос больше не разбит на три громоздких таблицы во `FROM`. Он идет единым понятным потоком.
